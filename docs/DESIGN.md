# DESIGN — 视觉与组件规范

## 风格

**干净、务实、不焦虑。**

用户在迷茫状态下打开产品，界面的第一任务是让他冷静下来，而不是刺激他。

- 白底深灰字，主色 `#2563EB`。
- 不用渐变、发光、庆祝动画、倒计时、排行榜。
- **不要游戏化**：不做积分、徽章、连续打卡天数排名、等级、虚拟形象。

## 色板

| 用途 | 值 | 实测对比度（白底） |
| --- | --- | --- |
| 主色 | `#2563EB` | 5.17:1 |
| 主色浅底 | `#EFF6FF` | — |
| 正文 | `#1F2937` | 14.68:1 |
| 次要文字 | `#4B5563` | 7.56:1 |
| 辅助文字（元信息） | `#676F7C` | 5.07:1 |
| 页面底色 | `#FFFFFF` | — |
| 分割 / 边框 | `#E5E7EB` | — |
| 提示底 | `#F9FAFB` | — |
| 警示（风险点、转介提示） | `#92400E` | 7.09:1 |
| 危险（排除方向） | `#B91C1C` | 6.47:1 |
| 成功（继续方向） | `#166534` | 7.13:1 |

语义浅底（同色系低透明度，固定成十六进制以便核算）：
`$color-warning-soft` `#F9F4F1` · `$color-danger-soft` `#FCF5F5` ·
`$color-success-soft` `#E8F0EB` · `$color-neutral-soft` `#F3F4F6`

> **这些值是算出来的，不是挑出来的。** 全部满足 WCAG 2.1 的 4.5:1（正文）。
> 改色前请先核算——曾有一版直接用了肉眼觉得「淡一点更高级」的灰，
> 实测只有 **2.54:1**（`#9CA3AF`），用在 12px 元信息上基本读不清。
>
> 已废弃、不要再用于文字：`#9CA3AF`（2.54:1）、`#3B82F6`（3.29:1）、
> `#B45309` 在同色底上（4.39:1）、`#2563EB` 在同色底上（4.49:1）。
> `#9CA3AF` 仍可用于禁用态与纯装饰 —— WCAG 对禁用元素不要求对比度。

### 标签配色

标签是「文字 + 同色系低透明度底色」，所以核算的是**文字色在该底色之上**的对比度，
而不是在白底上。几处曾不达标的已修正：

| 标签 | 处理 |
| --- | --- |
| 行业阶段·成长 | `#2563EB` → `#1D4ED8`（同色底上 4.49 → 5.72） |
| 行业阶段·衰退 / 低谷观察 | `#B45309` → `#92400E`（4.39 → 6.08） |
| 来源等级 深度媒体 | `#3B82F6` → `#2563EB` + 底色透明度降到 6%（3.29 → 4.77） |
| 行内代码 `<code>` | 用次要文字色而非辅助色（深底上 4.45 → 6.3） |

> 来源等级前 4 级原先靠「同一蓝色由深到浅」区分，但浅的那几档文字太浅。
> 现在改为**文字色只用深蓝三档，靠底色透明度递减表示可信度降低**——
> 既不丢「越往下越浅」的视觉梯度，文字又都够深。

## 文字

| 层级 | 字号 | 行高 |
| --- | --- | --- |
| 标题 | 18-20px | 1.4 |
| 正文 | 14-16px | 1.6 |
| 辅助 | 12-13px | 1.5 |

字重只用 400 / 500 / 600。不写全大写英文，不用斜体强调。

## 组件

### 卡片

- 圆角 `12px`，浅边框 `1px solid #E5E7EB`，不要重阴影。
- 内边距 `16px`。
- 标题一行超出省略；说明最多 3 行超出省略。

### 标签

低饱和：文字用语义色，底色用同色系约 10% 透明度。

| 标签 | 语义 |
| --- | --- |
| 行业阶段 | 五档各一色；衰退 / 低谷观察用警示色，不用危险色 |
| 来源等级 | 前 4 级（官方数据 / 招聘平台报告 / 券商研报 / 深度媒体）用主色系，靠深浅区分；后 2 级（从业者访谈 / 自媒体）用灰系 |
| 事实 / 观点 / 猜测 | 事实用主色，观点用灰，猜测用警示色描边 |

### 按钮

- **主按钮**：实心，底色 `#2563EB`，白字，圆角 `8px`，高度 `44px`。
- **次按钮**：描边，边框 `#D1D5DB`，文字 `#374151`，其余同上。
- 一屏最多一个主按钮。
- 文案用动词开头：「开始盘点」「加入实验」「记录今天」，不用「确定」「提交」这类无信息量词。

### 空状态

一句话 + 一个动作按钮，不要插画和长文案。

- 「还没有实验。选一个方向，先做 7 天。」
- 「暂时没有新的行业卡片。」

## 页面

| 页面 | 关键内容 |
| --- | --- |
| 首页 | 四个卡点入口 + 当前实验进度（若有） |
| 行业列表 / 详情 | 列表为卡片流 + 阶段筛选；详情突出阶段、岗位、风险、来源与日期 |
| 测评 / 结果 | 一屏一题；结果页给关键词 + 2-3 个方向 + 实验入口 |
| 信息雷达 | 每条显示来源等级标签、影响、行动点 |
| 计划 | 五层拆解从上到下，允许上层留空 |
| 实验列表 / 详情 | 列表分进行中 / 已完成；详情为 7 格记录 + 能量曲线 + 复盘入口 |

## 无障碍与兜底

- **正文对比度 >= 4.5:1，已逐页核算**（不是约定，是实测）。
  实测方式：遍历页面所有可见文字节点，沿祖先链合成有效背景色后计算对比度，
  覆盖 10 个页面。色值表见上方，改色后请重跑。
- 图标按钮必须有可读文字或 aria 标签。
- 心理风险相关内容（转介提示）用警示色且放在显眼位置，不做折叠。
- **可点元素最小 44×44px**（即 `$control-height`）。按钮、输入框、选择器统一按这个高度做。
  横向滚动的筛选 chip 是有意的例外：参考 Material 的 32dp 紧凑规格，高度约 35px，不要再压小。

## 窄屏

设计按 **320px 宽**兜底（最窄的常见手机），要求：

- 页面不出现横向滚动（`document.scrollWidth == viewport`）。
  唯一允许横向滚动的只有筛选 chip 行，它必须放在 `overflow-x: auto` 的容器里。
- 一行排 7 个的网格（如 7 天记录）在 380px 以下折成两行，保证每格不小于 44px。
  「一屏看完 7 天」让位于可点面积——趋势由下方的能量柱状图承担。

## 深色模式

**不支持**。应用是纯浅色设计，三处配置保证不被系统深色模式影响，
详见 `docs/ANDROID.md` 的「深色模式」一节。不要在样式里加 `prefers-color-scheme` 分支。
