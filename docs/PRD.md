# PRD

## 一句话

帮迷茫大学生在 **4 周内排除 1-2 个错误方向，确定 1 个可验证的下一步**。

不是给答案，是给下一步。用户离开产品时应该拿到一个「这周要做的具体动作」，而不是「你要多了解自己」。

## 用户

- 大二到大四本科生，尤其大三（面临实习选择）。
- 应届生，秋招 / 春招前后方向摇摆。
- 实习中但迷茫、不确定要不要留下来的人。

共同点：不缺努力，缺**判断依据**和**低成本试错的机会**。

## MVP 四件事

### 1. 行业地图

行业卡片，含：**阶段 / 岗位 / 技能 / 风险 / 来源**。

阶段枚举：萌发 / 成长 / 成熟 / 衰退 / 低谷观察。
每张卡的结论必须带来源和日期。

### 2. 探索测评

兴趣 + 价值观 + 经历盘点，自研题目（不抄官方量表）。

输出不是「你是 X 型人格」，而是：3-5 个关键词 + 2-3 个验证方向 + 1 个本周实验建议。

### 3. 信息雷达

每周 3 条可靠信息，标注来源等级、影响、行动点。

信息不是新闻摘要，必须回答「这对找方向的你意味着什么、你可以做什么」。

### 4. 计划与实验

```
五年假设 → 一年主题 → 本月实验 → 本周动作 → 复盘
```

实验闭环：选方向 → 写假设 → 7 天任务 → 每天记录能量和喜恶 → 第 7 天复盘 → 继续 / 排除 / 换方式。

## 不做

招聘、课程商城、社区动态、心理诊断、投资建议。

## 原则

1. **事实 / 观点 / 猜测分开标注。** 三者混在一起是这类产品最容易犯的错。
2. **行业结论带来源和日期。** 无来源宁可删掉，写「待核实」。
3. **测评不是诊断。** 不做心理疾病判断，不做「你适合什么」的断言，只做提示。
4. **不制造焦虑。** 不出现「再不规划就晚了」「同龄人已经」这类话术。
5. **严重心理问题转介专业咨询。** 出现自伤、持续失眠、抑郁倾向等表述时，给出转介提示，不做安慰式引导。

## 成功指标

| 指标 | 目标 |
| --- | --- |
| 注册 → 完成自我盘点 | 40% |
| 盘点 → 完成一次实验 | 20% |
| 次周留存 | 25% |
| 填写「方向更清晰了」的占比 | > 60% |

前两个是漏斗指标，第三个是习惯指标，第四个是价值指标。四个里若有一个明显不达标，先修那个，不加新功能。
