# T07 — 计划与实验

## 计划页（`src/views/Plan.vue`）

五层拆解，从上到下，**可编辑并保存到本地**：

```
五年假设 → 一年主题 → 季度项目 → 本月实验 → 本周动作
```

- 上层允许留空（不知道就先空着，不强制填）。
- 每层给一句填写提示，例如五年假设：「允许是猜的。」
- 保存写 `localStorage`。

## 实验列表（`src/views/ExperimentList.vue`）

分两组：**进行中 / 已完成**。空状态友好。

## 实验详情（`src/views/ExperimentDetail.vue`）

- 假设、方向、起止日期、状态
- **7 天日志**：每天记录 做了什么 / 能量(1-5) / 喜欢 / 讨厌
- 能量曲线（简单柱状即可，不用图表库）
- **复盘结论**：继续 / 排除 / 换方式

复盘页必须显式说明「**排除一个方向是有效结果**」。
