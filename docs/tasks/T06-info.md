# T06 — 信息雷达

## 内容

展示 3 条信息，每条含：`title` / `source_name` / `source_level` / `published_at` / `summary` / `impact` / `action` / `tags`。

## 要求

- **来源等级用不同颜色标签**：前 4 级（官方数据 / 招聘平台报告 / 券商研报 / 深度媒体）用主色系；后 2 级（从业者访谈 / 自媒体）用灰系。
- 事实 / 观点 / 猜测要分开呈现：`summary` 是事实，`impact` 是观点，需有视觉区分。
- 支持**按 tag 筛选**。
- 显示免责声明：**「示例数据，需人工核实」**。

## 验收

- [ ] 3 条信息完整渲染
- [ ] 来源等级标签颜色区分明显
- [ ] tag 筛选可用
- [ ] 免责声明可见
- [ ] `pnpm lint && pnpm build` 通过

## 输出

变更摘要、测试结果、下一步建议。
