# T03 — 首页 + 底部导航

## 目标

首页 4 个入口卡片 + 底部导航。

## 内容

### 首页（`src/views/Home.vue`）

4 个卡点入口卡片，点击跳转：

| 卡片 | 文案 | 跳转 |
| --- | --- | --- |
| A | 不知道有哪些行业 | 行业列表 |
| B | 不知道自己适合什么 | 测评 |
| C | 信息太乱、看不完 | 信息雷达 |
| D | 有方向但执行不下去 | 计划 |

每张卡：标题 + 一行说明。下方显示当前实验进度（无实验时显示空状态）。

### 底部导航

4 项：**首页、行业、信息、计划**。

- 当前项高亮主色 `#2563EB`。
- 图标用 emoji 或内联 SVG，不用图标库。
- 实验列表不占 tab 位，从首页进入。

## 验收

- [ ] 4 张卡片点击均能跳转
- [ ] 底部导航 4 项可切换，当前项高亮
- [ ] `pnpm lint && pnpm build` 通过

## 输出

变更摘要、测试结果、下一步建议。
